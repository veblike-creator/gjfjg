# AI Telegram Bot - готовый к деплою

## Файлы для загрузки на BotHost:
1. bot.py - основной код
2. requirements.txt - зависимости
3. Dockerfile - конфигурация
4. .env - переменные окружения

## Возможности:
✅ SQLite база данных (автоматически создаётся)
✅ Мультимодельный чат через AITunnel API
✅ SeedEdit генерация через GenAPI
✅ Загрузка фото на Telegraph.ph
✅ Premium система
✅ Админ панель

## Модели:
- GPT-4.1 Mini (бесплатно)
- GPT-4o (Premium)
- Gemini 2.0 Flash (Premium)
- Claude 3.5 Sonnet (Premium)

## Запуск:
Просто загрузи все файлы на BotHost и запусти!
